The owner picked B on 2026-10-01. A was deleted once B shipped, along with its dev routes. B lives in `src/components/landing/LandingPage.tsx`.

**`/` for a signed-out visitor.** `updateSession` rewrites a signed-out `/` to `/welcome` (`src/app/(landing)/welcome/page.tsx`), so the address stays `/` and a signed-in `/` is still the app. A direct `/welcome` redirects to `/`, so the page has one address. `/login` lost the demo button; it links to `/` instead. The demo's only door is the Landing Page's button.

Before capture, `npm run seed:demo:reset` refreshed "TEKGUYZ Demo", because its dates had aged and every card read Going Cold.

**Robots.** `src/app/robots.ts` allows crawling and closes `/api/`. Indexing is per page: the root layout says noindex, and only the Landing Page overrides it to index. Closes #22.

The Landing Page therefore sets neither; the root's card (name, description, branded image) is its card.
